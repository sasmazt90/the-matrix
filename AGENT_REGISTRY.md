# Agent registry
| Role | Data and tools | Output | Trigger |
|---|---|---|---|
| Orchestrator | Requested finding, registry and policy | Decision brief and owner | User question |
| programmatic | Read-only, scoped media evidence | Delivery diagnosis, missing supply evidence | DSP question |
| financial | Read-only, scoped Finance and media data | Margin at supported grain, missing costs | Commercial question |
| measurement-reviewer | Read-only, experiment and request | Evidence gap and proposed comparison | Causal question |
The three specialists are defined in .claude/agents. The local Node workflow runs independently. Call and cost accounting belongs in deterministic runtime instrumentation when a model provider is connected.
